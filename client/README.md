# Frontend (React 18 + Vite)

## Quick Start (Windows)

```bat
cd diabetes_poc_react
npm install
npm run dev
```

Vite proxies `/api` to `http://127.0.0.1:8000`.

## Pages

- Dashboard: seed data
- Visit: live evaluate & save
- Configurator: load/publish configs
- Visit History
- Notifications / Tasks (with "Process Events Now")
